## Como usar este caderno

Vocês chegaram com o **Canvas do Problema** (Aula 1) e o **Mapa de Evidências** (Aula 2). Vão sair com **uma solução candidata**, sustentada em evidência, com uma hipótese clara sobre por que funcionaria e um plano para testá-la com o cidadão na Aula 4.

São **10 etapas**, preenchidas em grupo, na ordem. Cada etapa usa o resultado da anterior. Preencham a lápis: quase tudo será reescrito ao menos uma vez, e isso é sinal de que o método está funcionando.

O Mapa de Evidências tem quatro seções, e cada uma alimenta uma parte do caderno:

| Seção do Mapa | Onde entra hoje |
|---|---|
| 1. Quem é o cidadão afetado | Etapa 2 (usuário específico) |
| 2. O que ouvimos e observamos | Etapa 1.1 (coluna da fala) |
| 3. O que os dados mostram | Etapa 1.1 (coluna do dado), Etapas 6 e 9 |
| 4. O que ainda não sabemos | Etapa 1.3, Etapa 2 e Etapa 10 |

**Três regras que valem do começo ao fim**

1. **O problema é do cidadão, não da corporação.** Se a frase começa com "o CBMDF...", voltem um passo.
2. **Nada entra aqui sem lastro.** Toda afirmação aponta para uma fala do campo ou para um dado verificado na fonte. O que for opinião do grupo é registrado como **suposição a testar**.
3. **Salvaguardas no uso de IA.** Dado pessoal ou sensível fica fora de ferramenta pública. Toda evidência sugerida pela IA é conferida na fonte. A análise e a decisão são do Oficial.

## Onde vocês estão: o Duplo Diamante

O percurso segue dois movimentos, repetidos duas vezes: **abrir** (levantar muitas possibilidades, sem julgar) e **fechar** (escolher, com critério). O primeiro par abre e fecha sobre o **problema**; o segundo, sobre a **solução**.

```
   1º DIAMANTE: O PROBLEMA           2º DIAMANTE: A SOLUÇÃO

         ______                            ______
       /   |   \                         /   |   \
     <     |     >                     <     |     >
       \   |   /                         \   |   /
         --|--                             --|--
  abrir    |  fechar             abrir      |  fechar
 DESCOBRIR | DEFINIR              IDEAR     | ESCOLHER E SUSTENTAR
  Aula 2   | Etapas 1 e 2      Etapas 3 a 5 | Etapas 6 a 9
```

| Movimento | O que se faz | Quando |
|---|---|---|
| Descobrir | Ouvir, observar e levantar dados, sem concluir | Aula 2 (feito) |
| **Definir** | Ler o campo com olhar crítico e enunciar **um** problema | **Hoje, Etapas 1 e 2** |
| **Idear** | Gerar soluções de naturezas diferentes | **Hoje, Etapas 3 a 5** |
| **Escolher e sustentar** | Escolher uma, explicitar por que funcionaria e como saberemos | **Hoje, Etapas 6 a 9** |
| Testar | Prototipar e levar ao cidadão | Aula 4 (a Etapa 10 prepara) |

> O erro mais comum nesse percurso é **fechar o primeiro diamante cedo demais**, com o problema mal definido. Uma solução excelente para o problema errado continua sendo desperdício de dinheiro público.

## Etapa 1: O que o campo nos disse *(≈ 30 min)*

Releiam o Mapa de Evidências com olhar crítico. A tarefa aqui é encontrar **onde a fala do cidadão e o dado não batem**, porque é ali que mora o que vocês ainda não sabem.

### 1.1 Quadro de triangulação

Para cada aspecto do problema, coloquem lado a lado uma afirmação da seção 2 do Mapa e um dado da seção 3. Escolham afirmações que apareceram em mais de uma entrevista ou que o grupo considera decisivas, indicando qual dos dois casos é.

| Aspecto do problema | O que o cidadão disse (fala anonimizada; em quantas entrevistas apareceu) | O que o dado mostra (fonte, ano, o que exatamente foi medido) | Relação |
|---|---|---|---|
| 1) | | | ( ) convergem ( ) divergem ( ) silêncio |
| 2) | | | ( ) convergem ( ) divergem ( ) silêncio |
| 3) | | | ( ) convergem ( ) divergem ( ) silêncio |

**Convergem:** apontam na mesma direção. **Divergem:** apontam direções diferentes. **Silêncio:** falta dado sobre o que o cidadão disse, ou ninguém falou sobre o que o dado mostra.

> Uma contradição entre o que se ouve e o que se mede costuma ser o achado mais valioso do campo: revela o contexto que a estatística sozinha esconde. Antes de comparar, confiram se fala e dado tratam da mesma coisa. "Demora" na boca do cidadão e "tempo-resposta" no sistema podem medir momentos diferentes.

### 1.2 Teste de viés

Para cada divergência ou silêncio, respondam: falta evidência mesmo, ou o resultado é efeito de como coletamos? Marquem os vieses que reconhecem no próprio trabalho:

( ) **Confirmação:** ouvimos principalmente quem já concordava com a hipótese da Aula 1
( ) **Seleção:** as entrevistas foram com quem estava mais acessível, e o território tem perfis que ficaram de fora
( ) **Sobrevivência:** só ouvimos quem chegou até o serviço; quem desistiu antes ficou sem voz
( ) **Desejabilidade:** o cidadão sabia que falava com o CBMDF e pode ter moderado críticas ou dito o que achava que queríamos ouvir
( ) **Evidência anedótica:** uma citação pessoal está sendo tratada como se representasse todos
( ) Nenhum destes, e conseguimos justificar por quê: _________________________________

> **Se o grupo só encontrou convergência,** desconfiem antes de comemorar. Ouvir apenas quem confirma a hipótese inicial é bem mais comum do que acertar o problema de primeira.

### 5.2 Prospecção de soluções semelhantes

> Que políticas semelhantes a **[alternativa X]** já foram testadas no Brasil e no mundo? Que resultado tiveram e onde eu verifico isso na fonte? **O que eu preciso saber do contexto de origem antes de considerar trazer isso para o DF?**

| Alternativa | Onde já foi tentada (com a fonte) | Que tipo de evidência é essa? | O que o contexto de origem tinha e o DF pode não ter |
|---|---|---|---|
| A) | | ( ) relato ou opinião ( ) antes e depois ( ) comparação com grupo similar ( ) sorteio | |
| B) | | ( ) relato ou opinião ( ) antes e depois ( ) comparação com grupo similar ( ) sorteio | |
| C) | | ( ) relato ou opinião ( ) antes e depois ( ) comparação com grupo similar ( ) sorteio | |

**Por que o tipo importa.** Um relato diz que alguém fez. "Antes e depois" diz que algo mudou, sem garantir que foi por causa da política. Comparação com grupo similar ou sorteio é o que permite dizer que a política **causou** a mudança. Essa é a diferença entre saber que funcionou e achar que funcionou.

**Por que a última coluna importa.** Uma política pode ter funcionado lá por condições que o DF não tem: renda, densidade, rede de saúde, hábito de acionar o serviço. Quem importa sem checar o contexto de origem está copiando, e é assim que uma solução que funcionou lá fracassa aqui.

## Etapa 8: Modelo Lógico simplificado *(≈ 18 min)*

A Teoria da Mudança explica **por que** funcionaria. O Modelo Lógico organiza **o que a solução faz na prática**. Hoje, apenas 3 colunas. A versão completa (insumos, atividades, produtos e resultados de curto, médio e longo prazo) é refinamento da semana, com apoio do docente, antes da Aula 5.

| O que fazemos (atividades) | O que entregamos (produto ou serviço concreto) | O que muda no cidadão, no curto prazo |
|---|---|---|
| | | |
| | | |
| | | |

**Confiram:** "o que muda" é o mesmo **"então"** da Teoria da Mudança? Se as duas frases divergem, uma delas está inflada. Corrijam agora.

*Exemplo de treino:* o que entregamos = "orientação de 3 passos entregue a 800 idosos"; o que muda no curto prazo = "idosos que moram sozinhos sabem o que fazer nos primeiros minutos". O que se espera depois ("se machucam menos") é resultado de médio prazo e entra na versão completa. Entregar e mudar são coisas diferentes, e a coluna do meio mede só a primeira.

### 9.2 Teste de comparação

Medir só "antes e depois" confunde o efeito da solução com o que já estava acontecendo: uma tendência de queda que vinha de anos, outra política que começou junto, um ano atípico. Para dizer que a solução **causou** a mudança, é preciso comparar com quem ficou sem ela.

**Opção A, a mais forte:** se a solução vai ser implantada em fases (por região, por unidade, por turma), **sortear** quem recebe primeiro. Quem recebe depois serve de comparação, e todos acabam recebendo.

**Opção B:** uma região administrativa que, nos dados do Mapa, vinha com a **mesma tendência** do indicador nos últimos anos. Ter o mesmo nível hoje ajuda pouco; o que sustenta a comparação é as duas estarem se movendo do mesmo jeito antes da solução.
